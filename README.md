# DNA → RNA & Protein Translator (Python)

A Python desktop application for DNA → RNA transcription and protein translation, with support for `.txt`, `.csv`, and `.fasta` files, GUI visualization, and Excel export.

---

## Features

- Translate DNA sequences to RNA and proteins
- Support for `.txt`, `.csv`, and `.fasta` file formats
- Automatic DNA cleaning and validation
- RNA transcription
- Protein translation starting from AUG codon to stop codons (UAA, UAG, UGA)
- Start and stop codons highlighted in the GUI
- Export results to Excel with:
  - RNA sequence
  - Proteins with codon:amino acid mapping
  - Stop codons
- Processes multiple files in parallel for faster execution

---

## Technologies Used

- Python 3.10+
- Tkinter (GUI)
- openpyxl (Excel export)
- functools (LRU cache)
- concurrent.futures (parallel processing)

## Project Structure
- `dna_protein_translator.py` — main GUI application
- `codon_table.py` — codon-to-amino acid mapping
- `requirements.txt` — project dependencies
- `sample_data/` — example DNA sequences (.fasta)
- `example_output/` — example Excel output generated by the program

## How the Program Works
1.	User selects input type:
- Single File
- Folder
2.	The program reads the sequences:
- For FASTA files, lines starting with > are ignored
- DNA sequences are cleaned and validated
3.	DNA is transcribed to RNA
4.	RNA is translated to proteins:
- Proteins start at AUG and end at the first stop codon (UAA, UAG, UGA)
5.	Results are displayed in a scrollable window with start/stop codons highlighted
6.	Results can be exported to Excel

## Example Usage
1.	Run the program:
```bash
python dna_protein_translator.py
```
2.	Choose input type:
- Single File
- Folder
3.	Select the desired file or folder.
4.	Choose the translation type:
- DNA → RNA + Proteins
- DNA → RNA only
- Proteins only

5.	View the results in the GUI or export them to Excel.

## Excel Export
The exported `.xlsx` file contains:
- RNA – transcribed RNA sequence
- Protein – translated protein sequence
- Codon:Aminoacid – codons and their corresponding amino acids
- Stop Codon – detected stop codon, if present
