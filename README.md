# DNA → RNA & Protein Translator (Python)

A simple Python application that translates DNA sequences into RNA and proteins.  
The program can process a single file or multiple files from a folder. It supports `.txt`, `.csv`, and `.fasta` files, highlights start and stop codons in the GUI, and allows exporting results to Excel.

---

## Features

- Translate DNA sequences to RNA and proteins
- Support for `.txt`, `.csv`, and `.fasta` file formats
- Automatic DNA cleaning and validation
- RNA transcription
- Protein translation starting from AUG codon to stop codons (UAA, UAG, UGA)
- Start and stop codons highlighted in the GUI
- Export results to Excel with:
  - RNA sequence
  - Proteins with codon:amino acid mapping
  - Stop codons
- Processes multiple files in parallel for faster execution

- `Homo sapiens chromosome 1 clone VMRC53-215D14, complete sequence.fasta` — Sample DNA sequence
- `Homo sapiens chromosome 17, clone hRPK.1053_B_8, complete sequence.fasta` — Sample DNA sequence
- `results.xlsx` — Example output generated by the program

---

## How the Program Works

1. User selects input type:
   - Single File
   - Folder
2. The program reads the sequences:
   - For FASTA files, lines starting with `>` are ignored
   - DNA sequences are cleaned and validated
3. DNA is transcribed to RNA
4. RNA is translated to proteins:
   - Proteins start at AUG and end at the first stop codon (UAA, UAG, UGA)
5. Results are displayed in a scrollable window with start/stop codons highlighted
6. Results can be exported to Excel

---

## Example Usage

Run the program:
python DNA_protein-translator.py
  •	Choose Single File or Folder
	•	Select the desired file(s)
	•	Choose translation type:
	•	DNA → RNA + Proteins
	•	DNA → RNA only
	•	Proteins only
	•	View results in GUI or export to Excel

## Excel Export

The exported .xlsx file contains:
	•	RNA: Transcribed RNA sequence
	•	Protein: Protein sequence
	•	Codon:Aminoacid: Codons and their corresponding amino acids (e.g., AUG:Met GCU:Ala)
	•	Stop Codon: Stop codon if present, otherwise —
